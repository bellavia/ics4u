This assignment gives you hands-on practice with the syntax covered in
the last lesson. Follow the same steps from
[Creating a TypeScript Project](3-organizing-projects.md) to create,
compile, and run a new file for this assignment, named:

```
u0-a2.ts
```

!!! note "Naming convention"
    `u0-a2` = Unit 0, Assignment 2 — following the same `uN-aN` pattern
    from ICS3U.

Write **one program** in `u0-a2.ts` that completes Tasks 1–5 below, in
order. Use `console.log()` to print the output of each task so it's
visible when you run the file.

!!! warning "Comment your code"
    Add a short comment above **each task** in your code, briefly
    explaining what that section does. See the Comments section of
    [Basic TypeScript Syntax](4-syntax-basics.md) if you need a
    refresher.

## Task 1: Variables and Types

*Knowledge — 3 marks | Communication — 1 mark*

Declare three variables: your name (`string`), your age (`number`),
and whether you are enrolled in this course (`boolean`). Print all
three values to the console.

## Task 2: Selection

*Knowledge — 3 marks | Communication — 1 mark*

Using an `if`/`else` statement, check whether your age variable from
Task 1 is 18 or older, and print `"You are an adult."` or `"You are a
minor."` accordingly.

## Task 3: Repetition

*Application — 4 marks | Communication — 1 mark*

Using a `for` loop, print the numbers from 1 to 10.

## Task 4: Arrays

*Application — 4 marks | Communication — 1 mark*

Create an array of at least 5 numbers of your choice. Using a `for`
loop, print each value in the array one at a time.

## Task 5: Functions

*Application — 4 marks | Communication — 1 mark*

Write a function that takes an array of numbers as a parameter and
returns their total sum. Call your function with the array you created
in Task 4, and print the result.

!!! note "Hint"
    You'll need a loop inside your function to add up every value in
    the array — similar to the loop pattern from Task 4.
