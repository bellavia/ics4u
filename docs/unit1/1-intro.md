# Lesson 1: From ICS3U to ICS4U

Welcome to ICS4U! This course builds directly on the programming
fundamentals from ICS3U, so before diving into new material, let's
briefly recap where you're coming from and where this course is
headed.

## What You Already Know

Regardless of which language your ICS3U course used, you should
already be comfortable with the core programming fundamentals:

- Setting up and navigating a coding environment
- Variables, data types, input and output
- Selection (`if`/`else` statements)
- Repetition (loops)
- Arrays
- Functions

You also learned how a computer actually runs your code — from source
code, down through compiling or interpreting, to binary, to the CPU
physically executing instructions. These concepts carry over
completely, no matter what language you used to learn them.

## The Language for This Course

This course uses **TypeScript**. If your ICS3U course used a
different language (Python, Java, or something else), don't worry —
the underlying programming concepts you already know (loops,
conditionals, functions, and so on) are the same; only the syntax
changes. We'll cover TypeScript's syntax and setup from the ground up
in the next lesson, so no prior TypeScript experience is assumed.

## What's New in ICS4U

ICS4U picks up where ICS3U left off, going deeper into how real
software is designed and built. Over this course, you'll build on the
programming fundamentals you already know, applying them to larger,
more structured programs — using TypeScript's compile-then-run
workflow, which you'll learn in the next lesson.

!!! note "New to TypeScript specifically?"
    That's completely fine. What matters coming into this course is
    your understanding of programming concepts in general — the
    TypeScript syntax itself is something we'll build together from
    Lesson 2 onward.

## Getting Set Up

The next lesson walks through setting up your Replit account, creating
a project, and using the Shell — from scratch, regardless of what
tools you used in ICS3U.
