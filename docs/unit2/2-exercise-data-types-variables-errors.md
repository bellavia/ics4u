# Exercise 2: Data Types, Variables, & Errors

**Previous:** [← Data Types, Variables, & Errors (Review)](2-data-types-variables-errors.md)

## Question 1

Create a new file named `u1-e02-1.ts`. **Without** using variables,
have your program calculate and output the following equations to the
console (all in the same file):

**a)** Five multiplied by three, minus seven

**b)** Four multiplied by three, divided by two

**c)** Multiply 5 by 3, then divide by 2 — *notice what happens to the
result compared to (b)*

**d)** Add 6 plus 5, then multiply by 3

## Question 2

Create a new file named `u1-e02-2.ts`. **Without** using variables,
output the following text to the console **exactly** as shown:

**a)**
```
Hello World!
Countdown from 5
4
3
2
1
Blast off!
```

**b)**
```
5.2 + 6.3 = 11.5
five plus five is 10
10 * 10 = 100, Goodbye!
```

!!! warning "Calculated, not hardcoded"
    For part (b), the values **11.5**, **10**, and **100** should be
    **calculated** by your code based on the equations shown — not
    typed in directly.

!!! note "Keep statements manageable"
    Try not to make any single `console.log()` statement too long —
    it's fine to use multiple statements for one question.

## Question 3

Create a new file named `u1-e02-3.ts`. Redo Question 2(b) so all the
calculations are stored into variables first, and your `console.log()`
statements use those variables.

## Question 4

Create a new file named `u1-e02-4.ts`. Create 3 variables: `year`,
`month`, and `day`. Make `year` equal `2023`, `month` equal `1`, and
`day` equal `20`. Output these variables so the result looks exactly
like:

```
2023/01/20
```

!!! warning "Requirements"
    - Your `console.log()` statement must use the variables — don't
      just output the string `"2023/01/20"` directly.
    - Try to output everything using **only one** `console.log()`
      statement.
    - Make sure the month outputs as `01` instead of just `1` (hint:
      the `0` can be added as a string literal).
    - Put a comment in your code describing what your program does.
